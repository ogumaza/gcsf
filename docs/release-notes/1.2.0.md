GCSF 1.2.0 adds an XMPlay plugin. The rest of GCSF is unchanged from 1.1.0.

GCSF rips Nintendo GameCube sequenced music into a PSF-family format. A rip plays with the game's code on an emulated GameCube: the game's OS, its sound library and its DSP program. The release comes with a ripper (`gcsfrip`), a renderer (`gcsfplay`), a foobar2000 component and an XMPlay plugin. `docs/gcsf.md` describes the format.

## Downloads

| File | Contents |
|---|---|
| `gcsf-1.2.0-win-x64.zip` | `gcsfrip` and `gcsfplay` for 64-bit Windows |
| `foo_input_gcsf-1.2.0.fb2k-component` | the foobar2000 component, for 64-bit and 32-bit foobar2000 v2 |
| `xmp-gcsf-1.2.0.zip` | the XMPlay plugin, for XMPlay 3.8.2 or later |

The programs run on Windows 10 or later and require no runtime DLLs. To install the component, open the file with foobar2000, or add it under Preferences › Components. To install the XMPlay plugin, unzip `xmp-gcsf-1.2.0.zip` and put `xmp-gcsf.dll` in XMPlay's folder, or in a folder inside it. Then restart XMPlay. For macOS, the README explains how to build from source.

## New in 1.2.0

- **XMPlay.** The XMPlay plugin plays `.minigcsf` files using their length and fade tags. The tags show in XMPlay. The `game` tag becomes the album, and `year` the date. XMPlay's Message window lists the other tags. The plugin's options page sets the default length and fade, endless playback and rendering ahead. During playback, the plugin renders ahead on a separate thread and saves the emulation's state as it goes. Seeking within the buffered audio is instant. XMPlay is a 32-bit program. The plugin is therefore a 32-bit DLL.

## Known limitations

- Only games with a driver profile can be ripped.
- Sounds that play until the game stops them, such as ambiences, get two loops and a fade when the ripper finds their loops. A sound that settles on a held note loops there. Other sounds play until their notes end, for at most ten minutes.
- Only sequenced sound is ripped. Use tools such as vgmstream for streams (`.ast`, `.adp`). Navi Trackers, a mode that only Four Swords Plus has, plays its music from streams.
- 34 of The Wind Waker's effects play nothing in a rip, and the ripper skips them. Each one reads a value that the game sets when it starts the effect, such as the material of the ground under a footstep. `docs/gcsf.md` lists them.
- Twilight Princess HD lacks one of the Wii's wave archives. `gcsfrip` warns about it. The sounds that use it play without its waves.
- The XMPlay plugin and the 32-bit foobar2000 component run the emulation more slowly than the 64-bit programs. On a slow computer, the busiest pieces may not play in real time in them.
- The output is stereo. Surround isn't played.
