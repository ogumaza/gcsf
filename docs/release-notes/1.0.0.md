GCSF 1.0.0 is the first release of GCSF. GCSF rips Nintendo GameCube sequenced music into a PSF-family format. A rip plays with the game's code on an emulated GameCube: the game's OS, its sound library and its DSP program. The release comes with a ripper (`gcsfrip`), a renderer (`gcsfplay`) and a foobar2000 component. `docs/gcsf.md` describes the format.

The programs run on Windows 10 or later and require no runtime DLLs. To install the component, open the file with foobar2000, or add it under Preferences › Components. For other systems, the README explains how to build from source.

## Features

- **Ripping.** `gcsfrip` rips a GameCube disc image (ISO, NKit, RVZ, WIA, GCZ, CISO or WDF) or an extracted disc. It creates a `.gcsflib` and a `.minigcsf` for each piece of music and each sound effect. `gcsfrip` plays each sound to determine its length and fade tags. Sounds that make no sound are skipped. `--bgm` rips only the music. Drag and drop also works.
- **The game plays the sound.** A rip holds the game's code. The player runs that code on an emulated GameCube, with the game's sound library and its DSP program. The sequencing, mixing, filtering and resampling therefore match the console. A game requires a driver profile. Version 1 has one for The Legend of Zelda: Four Swords Adventures (USA).
- **Rendering.** `gcsfplay` renders rips to WAV or FLAC at the GameCube's rate of 32,028 Hz.
- **foobar2000.** The component plays `.minigcsf` files with their length and fade tags. It supports tag editing, ReplayGain and endless playback. It renders ahead of playback on a separate thread and saves the emulation's state as it goes. Seeking back is instant. Seeking forward only waits for rendering to reach the target.

## Known limitations

- Only games with a driver profile can be ripped.
- Sounds that play until the game stops them, such as ambiences, get two loops and a fade when the ripper finds their loops. A sound that settles on a held note loops there. Other sounds play until their notes end, for at most ten minutes.
- Only sequenced sound is ripped. Use tools such as vgmstream for streams (`.ast`, `.adp`).
- The output is stereo. Surround isn't played.
