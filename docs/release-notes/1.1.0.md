GCSF 1.1.0 rips four more games: The Legend of Zelda: Four Swords Plus, The Legend of Zelda: Twilight Princess, The Legend of Zelda: The Wind Waker and Mario Golf: Toadstool Tour. It also rips Twilight Princess with the sound files of its Wii and Wii U releases, and The Wind Waker with those of The Wind Waker HD. GCSF 1.0.0's player and foobar2000 component play every rip that 1.1.0 makes.

## Downloads

| File | Contents |
|---|---|
| `gcsf-1.1.0-win-x64.zip` | `gcsfrip` and `gcsfplay` for 64-bit Windows |
| `foo_input_gcsf-1.1.0.fb2k-component` | the foobar2000 component, for 64-bit and 32-bit foobar2000 v2 |

The programs run on Windows 10 or later and require no runtime DLLs. To install the component, open the file with foobar2000, or add it under Preferences › Components. For macOS, the README explains how to build from source.

## New games

- **The Legend of Zelda: Four Swords Plus** (Japan). The Japanese release of Four Swords Adventures plays the same sequences with the same sound library. Its rips sound like the American release's.
- **The Legend of Zelda: Twilight Princess** (USA). The game loads its waves in groups, scene by scene. `gcsfrip` finds each sound's groups. A rip's `.gcsflib` holds only the wave archives of those groups.
- **The Legend of Zelda: The Wind Waker** (USA). The game's sound library is JAudio1, the first generation of JAudio. The game names none of its sounds. A rip names an effect after its category and index, for example `se4-0123`, and a piece of music after its file.
- **Mario Golf: Toadstool Tour** (USA): its 38 songs and 9 jingles. The game plays them through Factor 5's sound library, MusyX. The game's sound effects aren't ripped. A jingle begins with half a second of silence. The game waits that long before it plays a jingle.

## Other changes

- **Music that the game never plays.** Four Swords Adventures' sequence archive holds three songs that no sound of the game names: `filed_w_test`, `house` and `filed_w1`. `gcsfrip` now rips them as music. Each one is named after its file. `--list` shows them as unplayed. The game's other sounds rip as before.
- **Sound files from another release.** `--sound-files DIR` rips a GameCube disc with another release's sound files in place of the disc's. The Wii and Wii U releases of Twilight Princess store their sound files in the GameCube's formats. So does The Wind Waker HD. The game's code still comes from the GameCube disc. The README explains where to find the files. It also lists the pieces that each release changed.
- **File names.** A rip's file names keep characters outside ASCII. Bytes that aren't valid UTF-8 and invisible control characters still become `_`.
- **Damaged files.** When a rip's compressed program is cut short and its inflated data ends exactly on a 1 MiB boundary, the message is now "truncated program data". It was "corrupt program data".

## Known limitations

- Only games with a driver profile can be ripped.
- Sounds that play until the game stops them, such as ambiences, get two loops and a fade when the ripper finds their loops. A sound that settles on a held note loops there. Other sounds play until their notes end, for at most ten minutes.
- Only sequenced sound is ripped. Use tools such as vgmstream for streams (`.ast`, `.adp`). Navi Trackers, a mode that only Four Swords Plus has, plays its music from streams.
- 34 of The Wind Waker's effects play nothing in a rip, and the ripper skips them. Each one reads a value that the game sets when it starts the effect, such as the material of the ground under a footstep. `docs/gcsf.md` lists them.
- Twilight Princess HD lacks one of the Wii's wave archives. `gcsfrip` warns about it. The sounds that use it play without its waves.
- The output is stereo. Surround isn't played.
